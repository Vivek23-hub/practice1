27 Develop an Employee Management Lightning Web Component that allows users to add employee 
records with validation.The system should validate the following before saving: 
● Employee Name cannot be empty and must contain at least 3 characters. 
● Employee ID must be greater than 0 and should be unique. 
● Salary must be greater than 10,000 and less than 500,000. 
● Email addresses must follow a valid email format. 
● The department must be selected from the available list. 
● Joining Date cannot be a future date
1. Employee Name Validation
Rule Name
Employee_Name_Validation
Formula
OR(
    ISBLANK(Name),
    LEN(Name) < 3
)
Error Message
Employee Name must contain at least 3 characters.
2. Employee ID Validation
Rule Name
Employee_ID_Validation
Formula
Employee_ID__c <= 0
Error Message
Employee ID must be greater than 0.
3. Unique Employee ID

No validation formula needed.

Open:

Employee_ID__c Field → Edit

Check:

Unique

Click:

Save
4. Salary Validation
Rule Name
Salary_Validation
Formula
OR(
    Salary__c < 10000,
    Salary__c > 500000
)
Error Message
Salary must be between 10,000 and 500,000.
5. Email Validation
Rule Name
Email_Validation
Formula
NOT(
    CONTAINS(
        Email__c,
        "@"
    )
)
Error Message
Email must contain @ symbol.
6. Department Validation
Rule Name
Department_Validation
Formula
ISBLANK(TEXT(Department__c))
Error Message
Department must be selected.
7. Joining Date Validation
Rule Name
Joining_Date_Validation
Formula
Joining_Date__c > TODAY()
Error Message
Joining Date cannot be a future date.
